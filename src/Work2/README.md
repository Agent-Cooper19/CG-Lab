# 贝塞尔曲线与 B 样条曲线

## 实验概述

基于 Taichi 框架实现 De Casteljau 算法绘制贝塞尔曲线，并扩展支持均匀三次 B 样条曲线。实现 GPU 并行光栅化、反走样处理，以及交互式控制点编辑。

## 已实现的功能

### 1. De Casteljau 算法（GPU 并行版）

- 在 GPU 上递归线性插值，给定参数 t 计算曲线上对应点坐标
- 利用 `ti.func` 实现，编译时内联到 kernel 中
- 支持任意数量控制点（2~100 个）

### 2. GPU 光栅化绘制

- 曲线采样点数为 1001（t 从 0 到 1 均匀分布）
- 采用 Batching 策略：CPU 一次性计算所有采样点坐标，批量传输到 GPU
- GPU 并行遍历采样点，映射到像素坐标并点亮
- 避免 CPU-GPU 频繁跨界通信造成的卡顿

### 3. 交互式控制点编辑

- 鼠标点击实时添加控制点（红色圆点）
- 灰色线段连接相邻控制点，显示控制多边形
- 键盘 C 键清空画布
- 对象池技巧：预分配固定大小显存（100 个控制点），无效点坐标设为 -10 隐藏在屏幕外

### 4. 反走样（选做）

- 高斯距离衰减模型：计算像素中心到曲线精确浮点坐标的距离
- 距离越近权重越大，邻域像素获得不同透明度
- 有效消除曲线边缘锯齿，视觉平滑
- 按键 A 可实时开关反走样，对比效果

### 5. B 样条曲线（选做）

- 均匀三次 B 样条，每 4 个相邻控制点生成一段曲线
- n 个控制点生成 n-3 段曲线，平滑拼接
- 按键 B 在贝塞尔和 B 样条之间实时切换
- 支持局部控制：修改一个控制点只影响相邻几段曲线

## 贝塞尔 vs B 样条对比

| 特性 | 贝塞尔曲线 | B 样条曲线 |
|------|-----------|-----------|
| 控制方式 | 全局控制 | 局部控制 |
| 阶数 | 随控制点数增加 | 固定三次 |
| 控制点数 | 2 个起即可 | 至少 4 个 |
| 曲线经过 | 首尾控制点 | 不一定经过任何控制点 |
| 数值稳定性 | 控制点多时不稳定 | 控制点多时仍稳定 |

## 关键实现细节

### De Casteljau 算法核心

```
for t in range(NUM_SEGMENTS + 1):
    temp = copy(control_points)
    for level in range(n-1, 0, -1):
        for i in range(level):
            temp[i] = (1-t) * temp[i] + t * temp[i+1]
    curve_points[t] = temp[0]
```

### 均匀三次 B 样条基函数

```
N0(t) = (1-t)³ / 6
N1(t) = (3t³ - 6t² + 4) / 6
N2(t) = (-3t³ + 3t² + 3t + 1) / 6
N3(t) = t³ / 6
```

### 反走样高斯权重

```
weight = exp(-distance² / (2σ²))
σ = 0.6
邻域半径 = 1.5 像素
```

### GPU Batching 策略

```
CPU: 计算全部 1001 个采样点 → NumPy 数组
GPU: from_numpy() 批量传输 → kernel 并行点亮像素
```

## 实验观察

- 控制点较少时曲线平滑跟随控制多边形
- 控制点增多后贝塞尔曲线可能出现大幅摆动（全局控制特性）
- B 样条曲线始终紧贴控制多边形，表现出局部控制优势
- 反走样开启后边缘明显平滑，锯齿消失
- GPU 并行绘制即使在 1000 采样点下也能实时渲染
