# 光线追踪

## 实验概述

基于 Taichi 框架实现 Whitted-Style 光线追踪，使用迭代式光线弹射替代传统递归，实现硬阴影和镜面反射，并对比不同弹射次数的渲染效果。

```bash
python Ray_Tracing.py
```

GUI 面板说明：
- **Light X/Y/Z 滑块**：实时调整点光源位置，观察阴影变化
- **Max Bounces 滑块**：调整最大弹射次数（1~5），对比不同反射深度
- **AA Samples 滑块**：调整抗锯齿采样数（1~16）

## 已实现的功能

### 1. 场景搭建

- 无限大平面（y=-1.0），带黑白棋盘格纹理，漫反射材质
- 左侧红色漫反射球（-1.5, 0.0, 0），半径 1.0
- 右侧银色镜面球（1.5, 0.0, 0），半径 1.0，纯镜面反射
- 点光源，位置可通过滑块实时调节

### 2. Whitted-Style 光线追踪

- 主光线从相机出发，击中物体后根据材质分支处理
- 漫反射材质：Phong 光照模型计算颜色，包含环境光、漫反射和镜面高光
- 镜面材质：根据反射定律计算反射方向，生成次级射线继续传播
- 反射率 0.8，每次反射能量衰减

### 3. 迭代式光线弹射（GPU 适配）

使用 `for` 循环替代递归，通过 `throughput` 变量追踪光线能量衰减，适合 GPU 并行计算架构。

### 4. 硬阴影

从交点向光源发射阴影射线，检测路径上是否有遮挡物。被遮挡的区域仅保留环境光，产生清晰的硬阴影。

### 5. 自相交防护

所有次级射线（反射射线、阴影射线）的起点沿法线方向偏移 1e-4，防止浮点精度导致的自我命中（Shadow Acne）。

### 6. GUI 交互面板

- 光源位置实时调节（X/Y/Z 三个滑块）
- 最大弹射次数调节（1~5）
- 抗锯齿采样数调节（1~16）
- 画面实时更新

### 7. 抗锯齿（选做）

- 每个像素内随机偏移采样多次
- 采样结果平均后写入像素
- 有效平滑物体边缘的像素锯齿

### 8. 玻璃材质（选做）

- 代码中定义了 MAT_GLASS 材质类型
- 实现了斯涅尔定律折射函数
- 菲涅尔效应（Schlick 近似）决定反射/折射比例
- 全反射检测
- 使用俄罗斯轮盘赌在反射和折射间做选择

## 实验效果

| 弹射次数 | 效果 |
|----------|------|
| 1 | 仅直接光照，镜面球显示为黑色（无反射） |
| 2 | 镜面球开始反射场景，能看到地板和红球的倒影 |
| 3 | 镜面球中出现二次反射（镜中镜效果） |
| 4-5 | 更多次反射，细节更丰富 |

阴影效果：
- 拖动光源位置，阴影方向和长度实时变化
- 红球在地板上投射清晰阴影
- 镜面球也会在地板上产生阴影

## 关键代码结构

反射向量：
```
R = I - 2(I · N)N
```

迭代追踪流程：
```
throughput = 1.0
for bounce in range(max_bounces):
    hit, t, N, color, mat = scene_intersect(ro, rd)
    if not hit: 加入背景色, break
    if mat == MIRROR:
        ro = 交点 + N × 1e-4  (防自交偏移)
        rd = reflect(rd, N)
        throughput *= 0.8 × color
    elif mat == DIFFUSE:
        计算 Phong 光照 + 阴影检测
        final_color += throughput × direct_light
        break
```
