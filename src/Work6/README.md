# 质点弹簧模型

## 实验概述

基于 Taichi 框架实现质点-弹簧模型（Mass-Spring Model）的布料模拟，对比三种数值积分方法（显式欧拉、半隐式欧拉、隐式欧拉）的稳定性差异，并观察不同阻尼系数对布料行为的影响。

```bash

```

GUI 面板说明：
- **Integration Method**：点击切换三种积分方法（切换时会自动重置布料）
- **Pause/Resume**：暂停/恢复模拟
- **Reset Cloth**：重置布料到初始状态
- **Damping 滑块**：实时调整阻尼系数（0.1 ~ 10.0）

## 已实现的功能

### 1. 质点-弹簧模型

- 20×20 质点网格，共 400 个质点
- 三种弹簧类型（选做内容）：
  - **结构弹簧**（Structural）：连接水平/垂直相邻质点，抵抗拉伸
  - **剪切弹簧**（Shear）：连接对角线相邻质点，抵抗剪切变形
  - **弯曲弹簧**（Bend）：连接间隔一个质点的邻居，抵抗弯曲变形
- 共 2202 根弹簧
- 布料左上角和右上角固定，模拟悬挂效果
- 支持重力、阻尼力和弹簧力计算
- 速度钳制（max_velocity=50）防止数值爆炸

### 2. 三种积分方法

| 方法 | 稳定性 | 说明 |
|------|--------|------|
| 显式欧拉 | 差 | 大阻尼下可用，小阻尼时迅速发散爆炸 |
| 半隐式欧拉 | 较好 | 默认方法，图形学中常用，大部分参数下稳定 |
| 隐式欧拉 | 最好 | 定点迭代近似求解，计算量最大但最稳定 |

积分方法间可实时切换，切换时自动重置布料状态。

### 3. 阻尼系数对比

**阻尼 = 1.0**：布料自然下垂，有明显弹性，来回摆动幅度较大，需要较长时间才能稳定。符合真实布料的轻阻尼行为。

**阻尼 = 5.0**：布料缓慢下落，弹性明显减弱，摆动幅度小，很快趋于静止。表现为过阻尼状态，布料显得"粘稠"。

### 4. GUI 交互面板

- 积分方法选择按钮
- 暂停/恢复控制
- 重置按钮
- 阻尼系数实时调节滑块
- 当前状态显示

### 5. GPU 并行优化

- 使用 `@ti.kernel` 拆分初始化步骤，保证 GPU 同步
- 使用 `@ti.func` 内联力学计算，减少 GPU 启动开销
- 使用 `ti.atomic_add` 处理多线程弹簧力累加

## 存在的问题

### 1. 球体碰撞仍会穿模

这是当前代码最明显的不足。虽然添加了碰撞检测（`resolve_collision` 函数），包括指数级排斥力、法向阻尼和切向摩擦，但在以下情况仍会穿透：

- **高速运动时**：质点速度太快，一个时间步内直接穿过球体
- **布料边缘**：边缘质点受力复杂，更容易穿透
- **切换积分方法后**：重置瞬间布料从高处落下，动能较大

**原因分析**：
- 碰撞检测只在离散时间点检查位置，没有做连续碰撞检测（CCD）
- 排斥力虽然设为指数级，但时间步长 `dt=5e-4` 仍可能不够小
- 布料和球体的交互只靠力和位置修正，没有真正的物理约束求解

**改进方向**：
- 实现连续碰撞检测（CCD），检测质点运动路径是否穿过球体
- 减小时间步长或增加子步数
- 使用更严格的约束求解（如 SDF 约束投影）

### 2. 显式欧拉极易发散

阻尼设为 1.0 以下时，显式欧拉会在几帧内爆炸。这是显式方法的固有缺陷，不是代码 bug。实验中需要手动调高阻尼才能看到显式欧拉的正常运行效果。

### 3. 缺少剪切弹簧和弯曲弹簧的独立可视化

虽然实现了三种弹簧，但渲染时统一显示为灰色线条，无法区分弹簧类型。更好的做法是用不同颜色渲染不同类型的弹簧。

### 4. 隐式欧拉迭代次数固定

定点迭代次数硬编码为 3 次（`ti.static(range(3))`），无法根据收敛情况动态调整。

## 实验观察

| 阻尼 | 摆动幅度 | 稳定时间 | 布料行为 |
|------|----------|----------|----------|
| 1.0 | 大 | 长 | 自然弹性，真实布料感 |
| 5.0 | 小 | 短 | 过阻尼，缓慢粘稠 |

1. 半隐式欧拉在两种阻尼下都表现稳定
2. 切换到显式欧拉并降低阻尼，布料迅速爆炸
3. 隐式欧拉无论阻尼大小都保持稳定，但运动略显"迟钝"
4. 球体碰撞在低速时基本有效，布料能包裹在球体表面
5. 高速下落时布料边缘会穿透球体
